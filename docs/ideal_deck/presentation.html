2. Technical & ML Discipline
STATISTICAL RIGOR
  • Rare-Event Imbalance Discipline: Official cost revisions occur in only 1.4% of monthly project records.
  • Avoids the Accuracy Trap: A dummy model achieves 98.6% raw accuracy by predicting nothing. We strictly evaluate on PR-AUC.
  • Interpretable Baseline: Retains Logistic Regression alongside Gradient Boosting to verify feature coefficients.
  • Zero Data Leakage: Strict out-of-time temporal validation ensures future months are never leaked into training folds.
  • Sub-10ms API Telemetry: In-memory optimized Parquet queries allow instant sorting and multi-criteria filtering across 2,059 projects.
Benchmark Proof
Gradient Boosting delivers ~6x lift over random baseline in predicting rare cost revisions.
