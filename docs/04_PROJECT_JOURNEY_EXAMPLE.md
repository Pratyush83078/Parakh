# Inspecting a project record

Use this procedure to verify a project without relying on an invented case study:

1. Open the project directory and select a record using its official project ID.
2. Check report month, project fields, current rule score, signal coverage, and any quality status or warning.
3. Open the source PDF/page link and compare the displayed fields with the report.
4. Read the model score as an uncalibrated ranking signal. It is not a finding that a project will fail.
5. Use ministry/state peers as context only; peer projects can differ in scale, age, and scope.
6. Record a human review outside the app. A reviewer disposition and intervention history are not implemented yet.
